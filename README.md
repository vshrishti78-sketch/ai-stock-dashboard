# AI Stock Market Dashboard
A stock market dashboard built with python and Streamlit. It shows live stock data,technical analysis (like moving and RSI) and machine learning based price prediction.
##  About This project
This is my customized version of an open-source project.

-Forked and customized by **Shrishti Verma**

-Original project by [ErikThiart](https://github.com/ErikThiart/ai-stock-dashboard)  (MIT License)


##  Why I chose This Project
I am a B.tech CSE student.I choose this project to learn how a real world python project works:data fetching,charts,technical indicators,and a basic machine learning model.

##  What I changed 
- Replace US stocks with Indian stocks (NSE tickers with .NS)
- Set Reliance as the default stocks
- Showed price in rupees instead of dollars
 

##  Tech Used
Python,streamlit,scikit-learn

##  How to run
1. Install requirement: 'pip install -r requirements.txt'
2. Run the app: 'streamlit run stock_dashboard.py'
